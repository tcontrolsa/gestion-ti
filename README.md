# Gestión TI · Tcontrol

Frontend del Proceso de Soporte Tecnológico (TC-GI-PC-2.6), publicado con GitHub Pages en https://tcontrolsa.github.io/gestion-ti

Este repositorio solo contiene el sitio estático (HTML, CSS y JavaScript). Los datos viven en Google Sheets y se acceden mediante una API de Google Apps Script que exige iniciar sesión con un código enviado al correo corporativo.

**No edite estos archivos aquí:** se generan desde el proyecto fuente (`Procesos_TI/v2`) con `node tools/publicar.js`.
